# Spotify Voice Basic

Голосовой контроллер Spotify для Windows.

После запуска программа отображается в системном трее. Нажмите правой кнопкой
по значку `S`, чтобы выбрать действие:

- `Включить` — запустить распознавание и открыть микрофон;
- `Остановить` — временно остановить распознавание и закрыть аудиопоток микрофона;
- `Выключить` — полностью завершить Spotify Voice.

Зелёный значок означает, что распознавание включено, серый — остановлено.

Английские команды:

- `Spotify next`
- `Spotify pause`
- `Spotify play`
- `Spotify last` / `Spotify previous`
- `Spotify close the app`
- `Spotify volume up five/ten/twenty/fifty`
- `Spotify volume down five/ten/twenty/fifty`
- `Spotify mute` — отключить или вернуть системный звук

Русские команды используют отдельное обращение **Музыка**:

- `Музыка следующий`
- `Музыка пауза`
- `Музыка продолжи`
- `Музыка прошлый`
- `Музыка закрой приложение`
- `Музыка громче на пять/десять/двадцать/пятьдесят`
- `Музыка тише на пять/десять/двадцать/пятьдесят`
- `Музыка выключи звук` — отключить или вернуть системный звук

Команды громкости меняют общую громкость Windows, а не только Spotify.

Одиночные слова без обращения игнорируются. Одновременно может работать только одна копия программы.

После запуска `Install.cmd` готовый EXE, модели и кэш сборки хранятся в папке
проекта на диске `F:`. Ярлык автозапуска также ведёт прямо в эту папку.
